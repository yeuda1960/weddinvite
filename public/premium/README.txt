Premium Assets Directory
========================

This directory contains fixed premium assets used by the guest RSVP page.
These assets are NOT editable via the admin UI and should be uploaded manually.

Required Files:
----------------
- premium/media/envelope.mp4          (opening envelope video)
- premium/media/bg-music.mp3          (background music)
- premium/lottie/hero.json            (top hero lottie animation)
- premium/decor/flowers.svg           (flowers decoration SVG)
- premium/fonts/AmaticSC-Regular.ttf  (custom font - already uploaded)

Note: These files are referenced directly by the guest page code.
Do not move or rename these files without updating the code references.
